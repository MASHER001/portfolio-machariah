# Victor Lewis Machariah Portfolio

A modern personal portfolio for Victor Lewis Machariah, a Business Information Technology student and junior full-stack developer.

## Tech Stack

- HTML
- CSS
- JavaScript
- Responsive design
- Dark/Light mode

## Getting Started

Open `index.html` in your browser.

## Files

- `index.html` - website structure and content
- `style.css` - layout, colors, responsive design, and animations
- `script.js` - dark mode, mobile menu, scroll progress, reveal animations, and form validation
